# Devpost submission requirements

Saved from the user's form instructions on November 15, 2026. Prepare these fields independently for **Connect**, **GreyFinance**, and each remaining hackathon project.

| Field | Requirement |
| --- | --- |
| Project name | Maximum 60 characters; editable later. |
| Elevator pitch | Required short tagline; maximum 200 characters; editable later. |
| Thumbnail | Supply a project thumbnail. The pasted form does not state its dimensions. |
| About the project | Required Markdown story describing inspiration, what we learned, how we built it, and the challenges faced. Markdown and LaTeX are supported. |
| Built with | Up to 25 language, framework, platform, cloud service, database or API tags. |
| Try it out | Public demo, app/store and source URLs; multiple links supported. |
| Image gallery | Up to 15 JPG, PNG or GIF images; maximum 5 MB each; recommended ratio 3:2. |
| Video demo | Required YouTube or Vimeo URL; embedded at the top of the project page. A local MP4 or a scripted outline is not a public video URL. |
| Additional information | For judges and organizers; private unless otherwise specified. |
| Upload a file | Required; maximum 35 MB. Put multiple files into a single ZIP. |

Prepare a separate complete kit for each project. Use actual screenshots and accurate verified claims. Keep the wallet requirement and real regtest/payment evidence clear. A prepared kit does not establish a submitted Devpost entry; retain the published demo video URL and submission confirmation when available.

The user handles video rendering, export, upload, and entering the final URLs during submission. Keep GreyFinance and Connect video preview ports 4417–4420 stopped.
